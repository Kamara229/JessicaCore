# Запуск Кодекс Jessica — ноябрь 2026

Обновление мобильного клиента: до 600 исходящих сообщений или 24 часов на одну явно запущенную сессию (что наступит раньше).

## Как начать
1. Установите подписанный APK новой версии JessicaCore поверх существующей, сохранив приложение и его данные.
2. Разрешите службе Jessica Accessibility в настройках Android.
3. Откройте Jessica Core → Кодекс, подтвердите согласие и нажмите «Запустить Кодекс».
4. В открывшемся ChatGPT выберите требуемую существующую переписку с планом работы.
5. Нажмите «Чат выбран» на панели Jessica.

## Надёжность
- Если Groq возвращает HTTP 429, backend возвращает не завершающий сессию ответ; очевидные исследования CALIBRI обрабатываются без обращения к AI-интерпретатору.
- Отправка в ChatGPT осуществляется только после проверки выбранной переписки, точного черновика и нового маркера ответа.
- Не подтверждённые отправки и тесты не повторяются автоматически. Если чат или ответ не виден, новые сообщения не отправляются.
- У пользователя остаётся кнопка «Остановить Кодекс». 600 сообщений и 24 часа — предельный бюджет; после окончания можно вручную начать новую сессию.
- Исследовательские ветки CALIBRI, Supabase и секреты этим обновлением не затронуты.

## Требования
Открытый, разблокированный телефон, активное соединение, запущенный ChatGPT, разрешённая служба специальных возможностей; для продолжительных сессий желательно питание.
