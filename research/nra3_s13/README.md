# NRA2 3.0 S13 — causal relation-conditioned linguistic readouts (RESEARCH ONLY)

S12c PR #722 was the first **one-time** independent new Russian heldout diagnostic. Although the physically paid S11 three-way router changed selected hypotheses on 92 genuinely new words, it did **not improve heldout hard weak-route label agreement (52.17% S8b vs 50.00% S11)**. More importantly, it **cannot change earlier UPOS/role/UD predictions**, because in the S7/S11 architecture the relation recursion occurs only *after* the original grammar and semantic heads. The prior S12c diagnostic UPOS/role/head scores also used a full-final-prefix grammar/semantic embedding added to earlier word embeddings and therefore were **not strictly online-causal accuracy estimates**. This bias must not be concealed or fixed by rescoring the now-consumed heldout16.

**S13 architectural remedy:** rather than continuing to train a router that cannot influence linguistic predictions, add an explicit rank-8 *relation→linguistic readout* adapter. Relation state from six paid 3way GRU cycles feeds a physical 128→8 projection, an 8→(17 UPOS + 9 semantic role) low-rank correction and a per-latent-dimension 8-weight causal dependency pair-affinity correction. Every word's logits are computed **at that word's own last actual original Calibri token**; a future sentence-final hidden state is never applied to an earlier word. For dependency TRAIN supervision, the governor must already be a previously visible word; **all future-head and root gold labels are ignored** rather than leaked. No gold role/UD/class or text labels enter inference. This is an *output readout correction*, not iterative feedback/backprop into the earlier grammar/semantic transformer blocks. Future S14 may study real recurrent integration only after independently assessed S13.

**Physical bill (exact):** rank8 projection 1,024 FP16 values, low-rank class correction 208, 26 class biases, 8 dependency pair coefficients = **1,266 new parameters**, **2,581 bytes including full physical header/SHA256**. Original 43 native-C CB59 5-bit tensors and all 6,106,154 NRA parameters unchanged, original physically paid 39-FP16 S11 router unchanged. This readout uses physically charged FP16-dense tiny operators and never calls them 5bit. Original parent CALIBRI 43M + GT untouched. Raw standalone NRA+router+S13 adapter effective bpp remains ABOVE 0.7 unless separately compressed; no whole-system bpp or CPU claims.
