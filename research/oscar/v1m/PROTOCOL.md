## Established facts before this experiment

All validation concerns **real externally pretrained** original `karpathy/tinyllamas/stories42M.pt`, 41,689,600 unique FP32 weights, LLaMA-style original decoder **8×512** (NOT S142 CALIBRI 12×320), full original file SHA256 `fbe124df8794c2e033432c22b59cff64485455b4644046c52a456d0bbd8859fe`. Existing source is authentic K32/V8 indices plus original FP16 per-matrix centroids/scales, with two actual pretrained-FP32-calibrated eight-layer recurrent Green Tunnels: **v1F** FIRST and **v1G** LATER.

v1K CPU experiment [#44168224133](https://github.com/Kamara229/JessicaCore/actions/runs/44168224133) jointly updated four physically packed K32/V8 source matrix codes/scales + both FIRST and LATER GTs, training 72 steps against original teacher logits/hidden on only 12 TRAIN stories. Original first-token accuracy on public debug **19/36→11/36**, complete original teacher continuation **0/36→0/36**, repetition **0.090→0.351**. The follow-up exact six-way physical source/GT ablation v1L [#44169289573](https://github.com/Kamara229/JessicaCore/actions/runs/44169289573) proved (on the same public examples) that source-only new four matrices + OLD v1F FIRST and OLD v1G LATER kept **19/36 FIRST, 0/36 FULL**, repetitions .090, and hidden cosine slightly improved .4649→.4666. Replacing FIRST GT causes original first token 19→11; replacing LATER GT increases repetition .09→.38. Therefore **freeze FIRST GT**, freeze new four-source matrix codebooks, and calibrate only LATER GT.
