# Oscar v1D — on-policy correction of real student-generated prefixes

## Evidence driving this experiment
- Oscar v0 source encoder: independent physically encoded FP32→CB59/CB61 works but not arbitrary-quality proof; exact `prior_locked` inverse of the *same old compressed source* is 8/8 only.
- Oscar v1B real separately pretrained 135M teacher→43M student: **6/8 teacher FIRST tokens**, **0/8 full teacher sequences**, original S142 model **8/8 identical unchanged generated sequences and 6/8 correct gold**. New 12-layer, rank8, OFF-by-default paid FP16 teacher route physically trained 48 steps.
- Oscar v1C actual 8-token teacher-forced train from v1B: 64 actual optimizer steps, 3/32→14/32 teacher-forced tokens correctly predicted, but **0/8 greedy teacher FIRST and 0/8 greedy full**, repeated zeros `0000000000`; original S142 remained 6/8 old gold. Main defect: *exposure bias* and repeated frequent tokens.

## Distinct preregistered v1D algorithm
**Restart from immutable, actually trained and successful Oscar v1B FP16 source** (GitHub Action #44140306012, SHA `11f79c0e9fb4f67e92149a8bdaf083f65a2c135168b557c6c8fb6df0d97aeaee`, 123080 bytes), **NOT** collapsed v1C source. Preserve full Oscar-compiled original S142 original 12×320 43.26M model, original GT3/9, S126 Q2 all12 GT, S142 48 active trained progressive weights, S94/S95/S98. Keep all old weights frozen.

Real original FP32 independent pretrained teacher: pinned HuggingFaceTB/SmolLM2-135M-Instruct revision `12fd25f77366fa6b3b4b768ec3050bf629380bac`, 30 layers ×576, unique134515008. The **student architecture remains 12 layers ×320**, and we train only additional rank8 12-layer route (separate 122880 FP16 scalars bytes); no direct tensor reshape of teacher.

- The same original **4 previously disclosed S30 TRAIN** S95-routed prompts drive weight updates; **4 other previously disclosed TRAIN-debug** prompts monitor but never influence learning or checkpoint choice. No sealed independent QA/EVAL.
- Each optimizer step (48 total), independently **generate the student's actual greedy token sequence** with original S98 real KV-cache decoder **under explicit Oscar teacher route**, starting from student model's present policy (on-policy, NOT teacher-forced target).
- For every actual student prefix *until its first EOS*, query **independent teacher** on the same prompt plus that exact generated student prefix; collect true 49152-vocabulary teacher next-token logits and teacher's argmax, **without reading any undisclosed answer table**. Include first token and up to three later positions (maximum 4 on-policy predictions per update). If student prematurely emits EOS at step1, it contributes a teacher-targeted EOS correction at that position; do not train fabricated later positions.
- Feed those **actual student-generated previous-token IDs** into an independent **differentiable student forward** using actual original 12-layer Q2 + progressive prefill, true KV cache, first/later original S142 controllers, and active Oscar route. Compute position-dependent **full-vocab temperature=2 teacher KL + teacher greedy next-token CE** and a margin against premature EOS (unless original independent teacher actually expects EOS). Strong **first-token original v1B preference anchoring** and teacher-first margin guard to avoid v1C's 6/8→0/8 collapse. Downweight repeatedly targeted token IDs in one sequence rather than reinforcing `0` 8×.
- Persist real optimizer traces: student-generated prior tokens, authenticated teacher-reply hashes per generated-prefix state, per-token teacher target ranks, losses, nonzero full12 route UP/DOWN gradients.
- Save, re-load, authenticate updated complete rank8/12 FP16, and perform independently regenerated **8 previously disclosed TRAIN-debug** actual KV greedy outputs under teacher route. Also test original default route exact **8/8 token+EOS identity** and **6/8 gold** before+after, fail-closed. Report genuine teacher greedy first/full matches and premature EOS before/after, including any negative outcomes. Do not mistake teacher-forced success for normal greedy success.
- Package ONE actual Oscar-compiled original CB61 source, immutable original S142 all GT sidecar, ONE new Oscar FP16 teacher-only route, original S94/S95/S98 and byte-accounted runtime manifest. Assert nominal bpp <=0.7 based on 43,261,760 structural params. Also report conservative bpp using only 36,380,480 actual decoder core params (zero/seed-generated rank896 structures excluded): if >0.7, mark **unacceptable**. Real original FP32 teacher and teacher logits are never shipped.
- **No other S142 full 456+128/616 J7 replay, clean untouched QA/EVAL, real native CPU C>=90%, nor cross-architecture quality claim.** Model remains unpromoted even if TRAIN improves. No NRA/NRA2, main, LIVE, Render, Supabase, APK, Jessica chat test.

## Kill conditions
- v1B SHA or original S93/S142/S94/S95/S98 provenance mismatch, teacher SHA/dim mismatch, no true real original KV hooks, any source change to original S142 model, missing new FP16 route gradients, bad physical footprint or original default case regression.
- If actual full response matching remains 0/8, report failure and follow with EOS/pointer policy and sequence distribution debugging rather than arbitrary additional training.
