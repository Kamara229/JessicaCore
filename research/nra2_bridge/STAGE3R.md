# NRA2 S3R — independent S3Q actual native 43M CPU capture, frozen/no scores

**Source**: S3Q preregistration PR #632, CI #43525211488, SHA-locked
JSON commitment `5e9ea9cd66d5dedf0aa2cf574dcf78c8e0a7522c892f775fd8e9e014c46a26cb`.
16 directed graph topologies / 64 queries, new relative to S3G and S3M;
every family and query style has paired yes/no and no shortcut via header
or graph length. This is publicly preregistered research, *not* sealed QA.

S3R is a clone of the previously successful S3N **genuine frozen 43M
native CPU** S194 J7 acquisition, with 64 additional S3Q prompts instead
of previous 192 S3M prompts. It relies on exactly the previously
frozen S194 and original S160 S93 CPU profile, CPU layer 12 hidden
width 320, original immutable S3E, S3H and S3N previous provenance.
The same 616 original CPU generated-token hashes are compared to the
original S194 hashes (456+128 retained +32 negative control).
The existing original 584 fully correct EOS answers are unchanged.
The standalone frozen 2241p NRA read port remains zero output gate.

All 64 S3Q native prompts are first consumed as unlabeled text by
original frozen CPU with read-only hooks and generated original 616
J7 control; S3Q independent BFS gold adjacency, query src/dst, and
answer are materialized ONLY AFTER all original true CPU work finishes.
Physics: save and reload original frozen 43M [64,T,320] FP16 token
sequences, mask/length, final token vector and gold labels;
verify bytewise SHA and S3Q question identity order against immutable
preregistered artifact downloaded from CI, not just source text.

This step intentionally NEVER invokes the S3O adapted bridge,
never hardens edges, and never scores 64 yes/no research answers.
The prospective S3S evaluation is predeclared before any S3R model
score: **unchanged physical FP16 S3O adapter**
`40a8903d5419cd8641b5d01e75e429e10b449304b3ba140d2245bf7f8a9d00b6`,
unchanged frozen NRA 2241p; compare original soft graph edge
probabilities against **only** `p>0.5` hard predicted graph edges,
with *both source/target kept SOFT* in each arm. Report overall
64 and 16 per graph family, and yes/no false positives separately.
No new training, no threshold selection, no optimization on S3Q.

No LIVE Jessica ordinary chat test, no main/QA/TEST, Render,
Supabase, APK or original Calibri/Green Tunnel/NRA writes.
Gate stays 0. This can establish *graph topology transfer* only;
not novel-language performance, independently sealed final model
acceptance, genuine new decoder FULL+EOS, physical all-in bpp or
paired native CPU speed.
