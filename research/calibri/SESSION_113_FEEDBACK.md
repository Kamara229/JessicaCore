# CALIBRI Pro Max v113 — активационная компенсация на маленькой Pythia-14M

Продолжение фактического отрицательного v112. Разработка в отдельной исследовательской ветке, никаких изменений Jessica LIVE/main/Render/Supabase/APK.

**Идея:** принцип обратной связи (connectome-inspired functional coupling): не только весовая RMSE, а реальные выходы оператора на активности соседних блоков. Оставляем точно тот же физический v112 кодек: общие четыре K32 словаря из исходных весов, 5-битный поток и FP16 масштабы каждой строки. Разрешено менять ТОЛЬКО уже оплаченные FP16 масштабы строк.

Для каждого из трёх исходных методов v112 (global, layer_control, role) сравниваем по новому неиспользованному VALID:
* source_only: оригинальный физический архив v112.
* teacher_signal: калибруем коэффициенты строк по входным активациям исходной Pythia-14M на отдельных TRAIN текстах.
* student_signal: калибруем коэффициенты строк так, чтобы собственные входные активации сжатого ученика на тех же TRAIN текстах приближали выходные сигналы исходной модели.

Обе калибровки: единственный аналитический least-squares множитель каждой строки с заранее фиксированной усадкой 0,5 и ограничением [-2,2]. Кодовые книги, пятибитные индексы, смещения, порядок слоёв не меняются; ZIP сравнивается по настоящему полному источнику, каждая ревизия имеет полный CRC32 и SHA256. Данные FIT и VALID были записаны в v113/protocol.py до опыта; не подбирать параметры по VALID, не открывать официальный TEST v89.

Три базы × три режима = 9 версий полного 14M инференса, в которых временно восстановлены только 24 выбранных оператора; все остальные веса остаются оригинальными. Каждую версию проверяем на новых шести VALID текстах по teacher-relative KL, реальному NLL/перплексии, ошибке выходных активаций, двум настоящим 24-токенным генерациям. **Все архивы равного физического размера**, но выбранные матрицы всё ещё превышают 0,7 bpp и модель целиком не сжата. Результаты не обещают scientific PASS. После сравнения возможно потребуется совместная калибровка блоков уже в ученической траектории, а не изолированные поправки строк.
