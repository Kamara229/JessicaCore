# S4 independent source-only codec ablation — same 5bit/8 group physical budget

**Purpose:** S2 proved that full-135M CB59 information is severely distorted by first decoder layers and through layer 30 (FP32/CB59 hidden cosine ≈ 0.05 at final). No FP32 restoration of only embedding/output head recovered meaningful answers. S3 is studying whether 5×rank24 + all30/rank32 neural GT joint training can recover. S4 tests a genuinely *different* lever: **improve the global 5-bit quantization of the original pretrained FP32 135M itself** WITHOUT changing its number of codes or decoder ABI.

- Original trained checkpoint pinned `HuggingFaceTB/SmolLM2-135M-Instruct` 134,515,008 original unique params.
- Original CB59 reference S0 SHA `50eac24ba7d7a452c495f8adced2cdef3f9cc44e024217fc21d8f2cebb87413c`, 211 × 2D matrices, 11,229,303 physical bytes.
- Precommit exactly ONE alternative source-only codec: keep the **same 5-bit indices per 8-element group, 32×8 FP16 centroid dictionaries, FP16 row scales and tied aliases**, but increase representative original source vector samples per tensor from **4,096 to 8,192** and deterministic snapped integer-nearest centroid refinement passes from **5 to 12**. This uses **NO teacher activation/QA/TEST labels** and adds **ZERO additional inference parameters or code bits**. All original 1D tensors stay identical. Novel source must pass exactly same original alias/physical ABI.
- Measure total full original FP32 weight relative squared error (both old/new decoded weight streams), original decoder 0/1/10/20/30 hidden cos to the SAME pretrained FP32 for 4 **previously exposed TRAIN/DEBUG questions** only, actual 8-token greedy outputs and EOS, first-token agreement to FP32. These debug questions already appeared in S0 and S2; never train/choose model on new unseen QA/EVAL.
- Do NOT claim that smaller RMSE is proof of coherent text, or that codec is a breakthrough; if no actual response improvement, continue research under controlled negative result.
- Count original new archive physical bytes and check **<=0.66784 bpp direct** and **<=0.7 including scaled 5×24 / rank32 GT + parallel slots physically measured in S2 (without failed S1 bank)**, with explicit independent boundary conditions.
- No new runtime format or original pretrained FP32 inference dependency, no merging into LIVE. Existing 43M CALIBRI, NRA2, Jessica, Render, Supabase and APK unchanged.
